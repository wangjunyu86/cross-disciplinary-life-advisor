# 回到真实世界：模型整合（第24—25课）

> 本文是课程内容的原创操作性摘要，不是逐字稿。

## 第24课：回到真实世界（上）

**核心命题：** 现实中的成长通常同时依赖系统知识与情境经验；资源位置会影响机会，但不决定个人上限，应通过可验证、可逆的选择逐步扩大选择权。

### 模型

#### 秩序分界线理论
- **通俗解释：** 把资源、规则可见度和机会获取难度视为连续的情境差异，用来识别当前阻力，而不是给人划定固定阶层。
- **因果链：** 资源与规则可见度不同 → 试错成本和机会密度不同 → 需要选择不同的学习、连接与实验策略。
- **适用信号：**
- 评估当前资源与机会约束
- 设计低成本的职业或学习实验
- **边界：**
- 这是情境假设，不是人格或阶层标签
- 个人处境会变化，需用现实数据持续校正

#### 马太效应
- **通俗解释：** 已有成果有时会吸引更多资源，形成正反馈；反过来也可通过小胜利和外部支持逐步建立新循环。
- **因果链：** 可见成果 → 信任与资源增加 → 更易产生下一次成果；若缺少起点，可先创造低成本、可展示的小成果。
- **适用信号：**
- 已经有可放大的优势
- 需要设计第一个可见的小胜利
- **边界：**
- 正反馈并非不可逆，也不代表弱势者没有机会
- 资源增长仍受环境、运气与执行质量影响

#### 基础概率理论
- **通俗解释：** 不同城市、行业和路径的机会密度、竞争与失败成本不同，可作为选择时的先验参考，但不能替代个体信息。
- **因果链：** 环境基准率不同 → 同样投入的结果分布不同 → 选择前应比较机会、成本与自身匹配度。
- **适用信号：**
- 比较职业、行业或城市
- 需要降低仅凭个案做决定的偏差
- **边界：**
- 基准率会变化，必须注明数据时间和样本
- 群体统计不能直接预测某个个人的结果

#### 街头智慧
- **通俗解释：** 通过小规模实践、反馈和复盘形成的情境判断力，强调务实与适应，但需要与系统知识和伦理边界结合。
- **因果链：** 小实验 → 真实反馈 → 修正判断 → 积累可迁移经验。
- **适用信号：**
- 信息不完整但可以低成本试验
- 需要理解规则在真实场景中的运行方式
- **边界：**
- 经验可能带有幸存者偏差，不能替代证据
- 不得以务实为名突破法律、伦理或风险底线

#### 选择权理论
- **通俗解释：** 优先保留未来可转向的路径，例如可迁移能力、现金缓冲和多元联系；既有选择会带来成本，但通常不是完全不可逆。
- **因果链：** 可迁移资产与缓冲增加 → 转向成本下降 → 面对变化时可选择的路径增多。
- **适用信号：**
- 比较多个长期路径
- 希望降低一次选择失败的代价
- **边界：**
- 选择权也有维护成本，不能无限囤积
- 年龄和既有路径会影响成本，但不应被当作固定上限

### 常见误用
- 把资源位置或所谓“秩序分区”当作对个人价值和上限的判决。
- 只看成功个案，不查行业、城市或路径的基准率与失败成本。
- 把街头智慧误解为冒险、投机或绕过法律与伦理边界。
- 认为过去的选择完全不可改变，忽略转向成本可以通过小实验逐步降低。

### 与其他模型的连接
- 开头：课程进入第二部分，强调工具箱的重要性，区分书本智慧与街头智慧。
- 中段：分析阶层跃迁的路径，强调书本智慧与街头智慧的结合，以及基础概率和选择权的重要性。
- 结尾：总结城市选择和阶层跃迁的策略，强调实践和选择权的重要性。


## 第25课：回到真实世界（下）

**核心命题：** 跨学科模型应被当作可校正的工具：结合系统知识、现实反馈、个人约束与风险承受能力，选择适合当前阶段的行动，而不是按固定人群标签套用策略。

### 模型

#### 秩序分界线模型
- **通俗解释：** 用资源、机会密度、规则透明度和试错成本描述不同处境，帮助选择策略；编号分区只是一种课堂化简，不代表固定身份。
- **因果链：** 处境差异 → 可承担的风险和有效策略不同 → 先盘点约束，再选择稳健积累或小步试错。
- **适用信号：**
- 职业与人生规划
- 盘点资源、约束和可承担风险
- **边界：**
- 不能据此给个人贴阶层标签或宣判上限
- 分区边界主观且会随时间、地区和个体变化

#### 长期主义复利模型
- **通俗解释：** 在方向基本正确且能持续获得反馈时，稳定积累技能、信誉、关系和资产可能产生复利。
- **因果链：** 持续投入 → 能力与信誉沉淀 → 机会与回报增加；方向错误时则可能复利式放大损失。
- **适用信号：**
- 已有可验证的长期方向
- 希望积累技能、信誉或资产
- **边界：**
- 长期坚持不能替代方向校验
- 高波动环境下需保留现金、时间和退出选项

#### 弱联系网络模型
- **通俗解释：** 较松散的跨圈联系有助于获得新信息与机会，但关系价值来自互惠、可信和持续维护。
- **因果链：** 跨圈连接 → 接触非重复信息 → 增加机会发现 → 通过可信行动形成合作。
- **适用信号：**
- 职业转型或探索新行业
- 需要扩大信息来源
- **边界：**
- 弱联系不能替代需要深度信任的关系
- 不要把人际关系工具化或以数量代替质量

#### 街头智慧模型
- **通俗解释：** 在资源有限时，用合法、低成本、可逆的小实验获得真实反馈，并把经验沉淀为更好的判断。
- **因果链：** 小步行动 → 市场或环境反馈 → 复盘修正 → 累积能力与选择权。
- **适用信号：**
- 创业或职业探索初期
- 缺乏完整信息但可以安全试验
- **边界：**
- 不等于追逐短期风口或高杠杆下注
- 不能忽视法律、伦理、健康和现金流底线

#### 资产配置模型
- **通俗解释：** 根据目标期限、现金流和风险承受能力，在不同风险资产之间分散配置，重点是避免单次损失破坏长期生活。
- **因果链：** 明确目标与底线 → 分散风险来源 → 定期再平衡 → 提高长期生存与达成目标的概率。
- **适用信号：**
- 有稳定现金流并准备长期规划
- 需要控制集中度和回撤风险
- **边界：**
- 不存在保证收益的配置，历史表现不代表未来
- 高杠杆、应急金不足或不懂产品时应先降低风险并咨询持证专业人士

### 常见误用
- 把课堂分区当作客观、永久的社会分类，进而给自己或他人贴标签。
- 把长期主义理解为不复盘地坚持错误方向。
- 把弱联系等同于功利社交，忽略互惠和信任。
- 把街头智慧等同于短期投机，或把资产配置理解为高风险资产必然带来高收益。

### 与其他模型的连接
- 开头：强调跨学科思维的局限性，指出书本智慧与街头智慧的差异
- 中段：详细分析不同人群的职业选择与理财策略，结合秩序分界线模型与长期主义复利模型
- 结尾：总结不同阶层的生存策略，强调街头智慧与资产配置模型的重要性
