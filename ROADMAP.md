# Roadmap

## Next

- Collect feedback from the first 10 real users.
- Add anonymized, permission-based before/after case studies.
- Run the evaluation set across major compatible agents.
- Improve the weakest two decision scenarios based on observed failures.

## Later

- Add optional worksheets for option comparison and experiment tracking.
- Add more localized examples without changing the core workflow.
- Publish stable releases with evaluation notes.

## Not planned

- Pretending to replace licensed medical, legal, or financial professionals.
- Adding models only to make responses sound more sophisticated.
- Optimizing for long answers instead of better decisions.
