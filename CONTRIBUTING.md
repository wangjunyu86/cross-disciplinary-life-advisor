# Contributing

Thanks for helping improve the skill.

## Report a weak result

Open an issue with:

1. the original prompt, with private information removed;
2. the response or the relevant failing section;
3. which rubric dimension failed;
4. what a better decision process should have done.

## Propose a change

Keep changes tied to an observed failure or a clearly reusable decision pattern. Avoid adding generic advice, duplicated model summaries, or rules that apply only to one personal preference.

Before submitting:

- keep `SKILL.md` concise and route detailed material to `references/`;
- update examples or evaluation cases when behavior changes;
- preserve safety boundaries and user autonomy;
- run the skill validator if available.
