# Changelog

All notable changes to this project are documented here.

## [1.0.0] - 2026-11-16

### Added

- English-first README and a complete Simplified Chinese version.
- One-command Skills CLI installation.
- Visual repository preview and animated decision-to-action demo.
- Ten realistic usage prompts covering career, projects, habits, relationships, money, and learning.
- Behavioral evaluation rubric with explicit release thresholds.
- Contribution guide and public roadmap.

### Changed

- Repositioned the skill around concrete decisions and actions rather than abstract mental-model knowledge.
- Improved discovery language in `SKILL.md` and `agents/openai.yaml`.
- Added clear examples for career choice, sunk-cost review, habit design, difficult conversations, and multi-option decisions.
